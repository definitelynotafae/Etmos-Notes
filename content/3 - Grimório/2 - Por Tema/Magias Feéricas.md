# Magias Feéricas

Os principais temas incluem **ilusões**, **invisibilidade**, **mudança de aparência**, **manipulação da natureza** e, principalmente, **contratos**. Aqui está uma seleção de magias que combinam com esses temas:

---

## **Ilusões**

Ilusões utilizam principalmente de truques nos sentidos das vítimas, sendo as categorias **Alterações (Al)** e **Invocações (Ev)** as mais úteis.

### **Alterações (Al)**
Para Alterações, os objetos mais relevantes incluem:
- **Sentidos (Una)**
- **Mente/Pensamento (Imu)**
- **Pessoa (Ivi)**
- **Informação (Azi)**

Características que combinam bem:
- **Cheiro (Kar)**
- **Movimento (Tum)**
- **Paladar (Gus)**
- **Som (Mul)**
- **Velocidade (Ast)**
- **Ilusão (Alui)**
- **Visão (Ocul)**

#### **Exemplos:**
- **Alivi Alui (Alterar Pessoa Ilusão)** → Invisibilidade  
- **Alivi Kan (Alterar Pessoa Reflexo)** → Alterar aparência para ser igual a de outra pessoa  
- **Alimu Ocul Tum (Alterar Mente Visão Movimento)** → Fazer alguém ver sombras se movendo ao seu redor  

### **Invocações (Ev)**
Para Invocações, os objetos úteis incluem:
- **Animais (Ali)**
- **Pessoa (Ivi)**
- **Inanimado (Exa)**
- **Construção (Omu)**
- **Comida (Ibo)**
- **Terreno (Era)**

Características que combinam bem:
- **Ilusão (Alui)**
- **Movimento (Tum)**
- **Corpo (Phys)**
- **Velocidade (Ast)**
- **Luz (Lum)**

#### **Exemplos:**
- **Evali Mul Tum (Invocar Animais Som Movimento)** → Invocar uma ilusão de mosquito que faz barulho para distrair alguém  
- **Evora Rat Kan San (Invocar Vegetação Dimensional Espelho Círculo)** → Criar um círculo de cogumelos que funciona como portal *(Oficial)*  

---

## **Natureza**

Um dos marcos naturais mais conhecidos das fadas são seus círculos de cogumelos que atuam como portais. Para isso, uma combinação de **Invocar (Ev)** seguido de **Transportar (It)** pode ser útil, dependendo das combinações de objetos e características.

#### **Exemplo:**
- **Evora Rat Kan San (Invocar Vegetação Dimensional Espelho Círculo)** → Criar um círculo de cogumelos que atua como um portal  

---

## **Contratos**

Contratos envolvem uma forte conexão mágica entre o orador e a outra parte. As funções **Aprisionar (AR)**, **Controlar (ET)** e **Marcar (ES)** são ideais para isso.

### **Objetos Relevantes:**
- **Alma (Ala)**
- **Pessoa (Ivi)**

### **Características Importantes:**
- **Reflexo (Kan)** - Para garantir reciprocidade no contrato  
- **Idioma (Hin)** - Para simbolizar a importância das palavras  

#### **Exemplos:**
- **Apala Hin Kan (Aprisionar Alma Idioma Reflexo)** → Formação imediata de um contrato. Exemplo: "Poderia me dar seu nome?"  
- **Esala Hin Kan (Marcar Alma Idioma Reflexo)** → Registrar uma dívida ou promessa para ser cobrada no futuro  

---

## **Complementos Pendentes**
Ainda restam dúvidas quanto ao uso dos complementos **Adição**, **Variação** e **Derivação**. Se algum deles permitir a conexão de múltiplos objetos, seria perfeito para criar contratos mais complexos.
